# 근대건축사 8주차 (9/30 수) — 장식 논쟁 / 아르누보 / 시카고학파

지난 시간 복습: 수정궁, 에펠탑 → "엔지니어의 건축" / 오늘: 건축가들의 반응

## 1. 미술공예운동 (Arts and Crafts) — 영국
- 배경: 기계 대량생산 → 질 낮은 물건 넘침 → 반발
- 존 러스킨 (비평가): 손노동, 정직한 재료 강조
- 윌리엄 모리스: 디자이너, 사상가 / 수공예 부활
  - 레드하우스 (1859, 설계 필립 웹) = 모리스 자택
  - 붉은 벽돌 그대로, 기능 따라 평면 비대칭
- 한계: 수공예 → 비쌈 → 부자만 삼 (모순!!)
- 의의: "디자인이 사회 문제"라는 생각 → 독일공작연맹, 바우하우스로 이어짐 (9주차)

## 2. 아르누보 Art Nouveau (1890~1910경)
- 뜻: "새로운 예술" / 과거 양식 거부 → 자연(식물) 곡선
- 철을 장식에 적극 사용 ← 7주차 철과 연결
- 빅토르 오르타 — 타셀 주택 (브뤼셀, 1893)
  - 계단홀 철 기둥, 바닥/벽 덩굴 곡선 → 구조+장식 하나로
- 엑토르 기마르 — 파리 지하철 입구 (철+유리, 식물 모양)
- 가우디 (바르셀로나) — 카사 바트요, 카사 밀라, 사그라다 파밀리아(1882~ 아직 공사중)
  - 교수님: 가우디는 "카탈루냐 모데르니스모"로 따로 보기도 함 → 시험엔 아르누보 계열로 OK
- 매킨토시 — 글래스고 미술학교 (1897~1909) / 직선+곡선 섞음

### 비엔나 분리파 (Secession)
- 오토 바그너, 요제프 올브리히 → 분리파관 (1898, 금색 돔)
- 아돌프 로스 「장식과 범죄」 ★★
  - 장식 = 낭비, 시대에 뒤떨어진 것
  - 로스하우스 (빈, 1910~11) → 장식 없는 상부 입면 → 당시 큰 논란
- 흐름: 장식 많음(아르누보) → 장식 줄임(분리파) → 장식 거부(로스) → 근대건축

## 3. 시카고학파 ★★★ (시험 100%라고 하심)
- 1871 시카고 대화재 → 도심 다 탐 → 빠른 재건 필요
- 땅값 ↑ → 위로 올리자 → 고층
- 조건 3개: ① 철골(강철) ② 엘리베이터 ③ 내화 (불 안 타게)
- 윌리엄 르바론 제니 — 홈 인슈어런스 빌딩 (1885 완공)
  - 철골이 하중 대부분 받음 → "최초의 철골 고층"으로 흔히 소개
  - 교수님: "최초" 논쟁 있음, 답안에 "흔히 최초로 꼽히는" 이라고 쓰기
- 루이스 설리번 ★
  - "형태는 기능을 따른다 (form follows function)" — 1896 글
  - 웨인라이트 빌딩 (세인트루이스, 1891)
  - 고층 3단 구성: 기단(상점) / 몸체(사무실 반복) / 꼭대기(코니스, 설비)
    → 고전 기둥의 주초-주신-주두 비례를 빌려옴
- 시카고 창: 가운데 큰 고정창 + 양옆 여닫이창 → 채광+환기

## 4. 프랭크 로이드 라이트 (미국)
- 설리번 사무소 출신 ("나의 스승" = 설리번)
- 프레리 하우스 (초원주택): 낮고 긴 수평선, 깊은 처마, 중앙 벽난로, 열린 평면
  - 로비 하우스 (시카고, 1909~10)
- 유기적 건축 → 나중에 낙수장 (1930s, 범위 밖)
