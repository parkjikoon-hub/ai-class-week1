※ 교수님: "재료가 바뀌면 형태가 바뀐다" ← 오늘 핵심 문장 (2번 말씀하심)

## 1. 배경
- 18C 후반 영국 산업혁명 → 철 대량생산 가능해짐
  - 코크스 제철 → 철 값 ↓ → 건축/토목에 사용
- 인구 도시 집중 → 공장, 창고, 역, 시장 같은 "새 건물 유형" 필요
- 기존 양식(고전, 고딕) ↔ 새 재료 = 충돌
  - 겉은 석조 양식, 속은 철골인 건물 많았음 (= 이중적)

## 2. 철 (주철 → 연철 → 강철)
- 주철 cast iron: 압축 강함 / 인장 약함 → 기둥에 적합
- 연철 wrought iron: 인장도 OK → 보, 트러스
- 강철 steel: 19C 후반 대량생산 → 고층 가능해짐 (8주차 시카고와 연결!)

### 콜브룩데일 철교 (Iron Bridge)
- 1779, 영국 / 세계 최초 주철 다리
- 근데 접합 방식은 목조 짜맞춤 방식 그대로 → "새 재료 + 옛 사고방식"
- ★ 교수님 질문함: "왜 목조처럼 짰을까?" → 철로 짓는 방법이 아직 없었으니까

### 라브루스트 — 생트주느비에브 도서관 (파리, 1850 완공)
- 겉: 석조 / 열람실 안: 철골 아치 그대로 노출
- 공공건물 내부에 철을 "보여준" 초기 사례
- ?? 국립도서관도 라브루스트 → 다음 시간 확인

## 3. 수정궁 Crystal Palace ★★★
- 1851 런던 만국박람회 전시장
- 설계: 조지프 팩스턴 — 원래 건축가X, 정원사/온실 설계자
- 철 + 유리 / 공장에서 만든 부재 현장 조립 = 프리패브 (prefab)
- 길이 약 560m / 공사 1850~51 몇 달 만에 완공
- 모듈(같은 크기 반복) 설계 → 빠른 시공 + 해체 후 이전 가능
  - 실제로 박람회 끝나고 시든햄으로 옮겨 재조립 → 1936 화재로 소실
- 의미:
  1) 양식 아닌 "구축 방식"이 형태 결정
  2) 표준화, 대량생산의 시작
  3) 당시 비평가들은 "건축 아니다"라고 비판 (러스킨 등) → 8주차 미술공예운동과 연결

## 4. 에펠탑
- 1889 파리 만국박람회 (프랑스 혁명 100주년)
- 귀스타브 에펠 = 구조 엔지니어 (다리 많이 설계)
- 연철 / 높이 약 300m → 당시 세계 최고 높이 구조물
- 파리 예술가들 반대 서명 → "흉물" 논란 → 지금은 상징
- ★ 수정궁 vs 에펠탑 비교 서술 → 시험 단골이라고 하심!!
  - 공통: 만국박람회, 철, 엔지니어 주도, 조립식
  - 차이: 수정궁 = 철+유리, 넓은 "공간" / 에펠탑 = 높이, "구조 자체가 형태"

## 5. 엘리베이터
- 오티스 안전장치 엘리베이터 → 1850년대 공개 시연
- 줄 끊겨도 안 떨어짐 → 사람이 높은 층 사용 가능
- 철골 + 엘리베이터 = 고층건물 두 조건 (8주차 시카고학파)

## 6. 철근콘크리트 (RC)
- 콘크리트: 압축 강 / 인장 약 → 철근(인장) 넣어서 보완
- 조제프 모니에: 정원사, 화분 만들다가 철망 넣은 콘크리트 특허 (1867)
- 프랑수아 엔비크: 1892 특허 → 기둥, 보, 슬래브 일체식 체계
- 오귀스트 페레: 프랭클린가 아파트 (파리, 1903~04)
  - RC 골조를 입면에 드러냄 / 골조 사이 패널
  - 르코르뷔지에가 페레 사무소에서 일함 → 9주차 연결
- 교수님: "RC는 20세기 건축의 기본 재료. 9주차 도미노 시스템이랑 꼭 같이 공부"
