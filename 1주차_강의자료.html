STEP 1 · 기본 도구

1-1 Git 설치

⊞윈도우 · 사이트에서
  1. 브라우저에서 git-scm.com/install/windows
  2. x64 설치 파일 받기 (대부분의 노트북)
  3. 받은 파일 실행 → 허락 창 예
  4. 아무것도 바꾸지 말고 Next만 → Install → Finish
설치 화면이 열 장쯤 됩니다. 읽지 않고 Next만 눌러도 됩니다.
⌘맥 · 먼저 확인, 없을 때 설치
git --version
  1. Git은 명령 프로그램이라 터미널에서 확인하는 것이 가장 정확합니다
  2. git version 2.… 숫자가 나오면 설치되어 있습니다 → 끝
  3. 숫자 대신 설치 창이 뜨면 설치 → 동의
  4. 창이 안 뜨거나 숫자가 안 나오면 xcode-select --install 입력 → 설치
  5. 새 터미널에서 git --version을 다시 확인합니다
맥에 Git이 항상 완전히 설치된 것은 아닙니다. Command Line Tools만 설치하면 되고, 큰 용량의 Xcode 전체는 필요 없습니다.
왜 설치하나 · Git은 저장할 때마다 무엇을 바꿨는지 기록해 둡니다. AI가 파일을 망쳐도 전 상태로 되돌릴 수 있습니다.

SCENE 1 · 블렌더 실시간

바닥 크기는 가로 12m, 세로 9m, 층고는 3.3m.
2층은 남쪽으로 2m 튀어나오게 하고 지붕은 평지붕으로.
층마다 이름을 1F, 2F, 3F로 붙여 줘.
다 만들면 남동쪽 위에서 내려다보이게 화면을 맞춰 줘.

창 높이 1.2m, 바닥에서 0.9m 위.
1층 동쪽 벽에는 폭 1m, 높이 2.2m 출입문 구멍을 뚫어 줘.
유리는 얇은 판으로 따로 만들어 넣어 줘.

Part 8 · MUST KNOW

AI를 쓸 때 꼭 지킬 네 가지

① 썼다면 썼다고 밝힌다

과제에 AI를 썼으면 어디에 썼는지 적습니다. 수업마다 허용 범위가 다르니 먼저 확인합니다.

② 남의 것은 확인하고 쓴다

사진 · 글꼴 · 글은 출처와 이용 조건을 확인합니다. AI가 가져온 사진도 마찬가지입니다.

③ 개인정보는 넣지 않는다

주민번호 · 전화번호 · 비밀번호는 AI에게도, 웹페이지에도 넣지 않습니다.

④ 숫자 · 법규 · 출처는 직접 확인

AI는 그럴듯하게 틀립니다. 특히 면적 · 법규 · 인용은 원문을 찾아봅니다.

COMMON MISTAKE

블렌더는 주소로 붙이지 않습니다

커스텀 커넥터 추가 + 주소 = ✗

blender.org 주소를 넣으면 "서버를 확인할 수 없습니다 · 301 · 찾을 수 없음"이 뜹니다.

왜?

블렌더 연결은 인터넷 주소가 아니라 내 컴퓨터에 설치하는 연결입니다.

취소를 누르고, ③처럼 커넥터 목록에서 Blender를 찾아 추가합니다.
STEP ④ · 블렌더에서 · 처음 한 번

④ 블렌더에 애드온 넣기 · 끌어다 놓기 두 번

  1. 블렌더를 켜 두고, 브라우저에서 blender.org/lab/mcp-server
  2. Drag and Drop into Blender 링크를 블렌더 창으로 끌어다 놓기 → 저장소(lab) 추가를 허용
  3. 같은 링크를 한 번 더 끌어다 놓기 → 애드온 설치
링크를 누르면 zip 파일만 받아집니다. 그때는 블렌더 Edit → Preferences → Get Extensions → 오른쪽 위 ⌄ → Install from Disk로 그 zip을 고릅니다.
STEP ⑤ · 블렌더를 켤 때마다

⑤ 블렌더 안에서 서버 켜기

  1. 블렌더 메뉴 Edit → Preferences (맥도 같음)
  2. 왼쪽 Add-ons → 검색창에 MCP
  3. BlenderMCP를 켜고 → start MCP server
  4. 처음 한 번은 Claude 앱을 완전히 종료했다가 다시 열기
완전히 종료: 윈도우는 작업 표시줄 오른쪽 아래 Claude 아이콘을 오른쪽 클릭 → 종료 · 맥은 Cmd+Q
