## 처음 한 번만 준비하기

1. GitHub 화면에서 초록색 **Code** 버튼을 누릅니다.
2. **Download ZIP**을 눌러 파일을 받습니다.
3. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 선택합니다.
4. 압축을 푼 폴더 이름을 `ai-class`로 바꿉니다.
5. `ai-class` 폴더를 `C:\` 바로 아래로 옮깁니다.

완료된 위치는 `C:\ai-class`입니다.

## 강의자료 열기

1. 파일 탐색기에서 `C:\ai-class`를 엽니다.
2. `1주차_강의자료.html`을 두 번 클릭합니다.
3. 웹 브라우저에서 강의자료가 열리면 준비 완료입니다.

## 폴더 구성

- `1주차_강의자료.html`: 학생용 웹 PPT
- `images`: 웹 PPT에 사용하는 그림
- `examples`: 수업 실습용 예제 파일과 `DESIGN.md` 예시
